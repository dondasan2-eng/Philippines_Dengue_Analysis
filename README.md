# Philippines Dengue Analysis (2026-2050 Forecast)

This project analyzes DOH Dengue data 2016-2021 and forecasts cases up to 2050 for 17 regions in the Philippines.

## Methodology
- Models: Linear Regression & Decision Tree
- Training: 10 cycles
- Forecast: 2022-2050 (5916 rows) - focus analysis 2026-2050
- Features: Year, Month, Region

## Files
- doh-epi-dengue-data-2016-2021.csv (source)
- project_code.ipynb (10 cycles code)
- prediction_2026_2050.csv (5916 predictions with LR & DT)

## Results
Successfully generated 25+ year forecast showing increasing trend in rainy months (June-Oct). Ready for thesis defense.
